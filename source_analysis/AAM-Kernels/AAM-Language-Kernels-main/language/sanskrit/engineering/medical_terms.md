# Sanskrit Medical Terms (Axis 9: Ayurveda)

## Diagnostic Ontology
- `√pariksha` — VALIDATE; examination and diagnostic checking.
- `√sthiti` — STATE; current condition snapshot.
- `√drishti` — OBSERVE; external signs and observations.
- `√smriti` — MEMORY; prior state and precedent retention.
- `√shanka` — DOUBT_INDEX; uncertainty/risk marker.

## Clinical Semantic Patterns
- Observation -> State model -> Validation -> Risk signal.
- Conflicts are logged as semantic events and escalated per governance.

## Integration Note
Axis-9 provides a controlled diagnostic vocabulary for biomedical intent normalization without embedding treatment logic in the language kernel.
