# Sanskrit Engineering Terms (Axis 8: Silpashastra)

## Structural Patterns
- `√stambha` — SUPPORT element; load-bearing anchor.
- `√bhitti` — BOUNDARY constraint; interface separator.
- `√vastu` — SITE model; placement and topology baseline.

## Flow Patterns
- `√srota` — LIQUID_FLOW channel behavior.
- `√vidyut` — ELECTRIC_FLOW transfer logic.
- `√tapa` — HEAT_FLOW dissipation/thermal exchange.
- `√vata` — GAS_FLOW pressure and transport semantics.
- `√pranali` — CHANNEL pathing and conduit topology.

## Normative / Compliance Patterns
- `√pramana` — STANDARD_CHECK against normative bounds.
- `√tula` — COMPARE measured vs reference values.
- `√pariksha` — VALIDATE operational state against constraints.
