# Sanskrit Specialized Terms (Axis 10: Yantra)

## Control and Orchestration
- `√shas` — CONTROL: command/governance primitive.
- `√sutra` — ALGORITHM: compact procedure chain.
- `√sthapana` — DEPLOY: installation and activation primitive.
- `√kri` — TRANSFORM: controlled state mutation.

## Automation Patterns
- Control loop: `√drishti` -> `√tula` -> `√shas`
- Deployment chain: `√sutra` -> `√sthapana` -> `√pariksha`

## Operational Note
Axis-10 terms define automation intent and lifecycle actions, suitable for integration with SCADA/CAD process gateways and service orchestration.
