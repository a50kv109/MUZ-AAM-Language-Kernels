## 🚀 Installation & Quick Start

### Web Application

Requires **Node.js 20+**:

```bash
# 1. Clone the repository
git clone https://github.com/aam-research/universal-language-kernel-harvester.git
cd universal-language-kernel-harvester

# 2. Install dependencies
npm install

# 3. Start development server on port 3000
npm run dev

# 4. Build production bundle
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Python Modules

Requires **Python 3.8+** (no mandatory external dependencies for core analysis):

```bash
# Run unit tests across all kernels
python3 -m unittest discover tests

# Or run specific test modules
python3 tests/test_aam_core.py
python3 tests/test_georgian_core.py
python3 tests/test_panini_and_bell.py
```
